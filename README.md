# `out/` -- derived results

Everything here is derived from the four source datasets by the scripts in `work/` and
`out/protocol_audit/`. The source data itself is not redistributed (see `DATA_SOURCES.md`).

## Per-panel tables

Each panel writes the same family of files, named `panel<X>_<what>.csv`:

| File | Contents |
|---|---|
| `panel<X>_matrix.csv` | the central table: methods (or metrics / generators) x evaluation protocols |
| `panel<X>_rank_ci.csv` | two-level bootstrap confidence interval for every cell of the matrix |
| `panel<X>_agreement.csv` | pairwise rank Spearman between protocols |
| `panel<X>_top3_jaccard.csv` | pairwise top-3 set Jaccard between protocols |
| `panel<X>_instability.csv` | per-method rank instability across protocols |
| `panel<X>_top1.csv` | the winner under each protocol (Panels C and D) |
| `panel<X>_boot.npz` | raw bootstrap tensors, for secondary analysis without re-running the sweeps |
| `panel<X>_results.md` | the author's per-panel working notes (**Chinese**; the English write-up is the manuscript) |

## The five analysis rows

| Row | Dataset | Object ranked | Role in the argument |
|---|---|---|---|
| A | Overath et al. (2025) | 243 scoring methods | wet-lab labels, the main sensitivity sweep |
| B | Cao et al. (2022) | 37 methods | 74-fold scale-up: does more data settle the protocol question? |
| C1 / C2 | ProtDBench (Liu et al., 2026) | 7 generators | deterministic labels, so zero external label noise |
| D | Adaptyv EGFR (Cotet et al., 2025) | 35 metrics | prospective SPR measurements, the deployment-like arm |
| E | all of the above | audit cards | the cross-panel roll-up (`protocol_audit/`) |

`protocol_audit/` holds the toolkit, its two real-data demonstrations, the generated audit
cards (`protocol_audit/reports/`) and the cross-panel card
(`protocol_audit/cross_panel_card.{csv,md}`).
